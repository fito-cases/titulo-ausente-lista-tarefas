# Estado inicial

A página `index.html` oferece cadastro, consulta, busca, edição, exclusão e persistência local das tarefas. No cadastro sem título (vazio ou só com espaços), a tentativa é rejeitada sem orientação suficiente para compreender a exigência nem retomar a tarefa. A rejeição não cria tarefa inválida. Descrição e data permanecem opcionais; o cadastro com título válido e as demais ações continuam disponíveis. O caso não requer build ou testes automatizados; confira a interação no navegador.
