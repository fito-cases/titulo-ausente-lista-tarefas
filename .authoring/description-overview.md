# Um título ausente no cadastro de tarefas

Uma lista de tarefas em HTML funciona no navegador, mas a tentativa de cadastrar sem título deixa quem a usa sem orientação suficiente. Neste caso diagnóstico de 45 minutos, você examinará a interação, justificará sua avaliação pela heurística de reconhecimento, diagnóstico e recuperação de erros e melhorará o fluxo sem perder o CRUD nem a persistência. Você também considerará como lidar com uma condição previsível de entrada inválida, mantendo descrição e data opcionais.

Para começar, abra o caso no Fito e explore o cadastro na página `index.html`. O trabalho inclui uma alteração na interface e uma explicação do diagnóstico. Não é necessário instalar uma ferramenta de build.
